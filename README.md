# DeciFresh

Decision Intelligence for Fresh Produce

DeciFresh is an AI-powered decision intelligence system that evaluates fresh-produce batches and determines their highest-value next action using freshness, market, demand, logistics, and waste-risk signals.

The core idea is simple: we don't just predict spoilage. We predict the highest-value future for every produce batch.

## Tech Stack

Python, FastAPI, CrewAI, Groq, HTML, CSS, JavaScript.
