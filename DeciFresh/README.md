# DeciFresh

AI-powered decision intelligence for fresh produce.

DeciFresh evaluates produce batches across freshness, market demand,
pricing, logistics and waste risk to recommend the highest-value
next action.

## Core Idea

Instead of asking:

> "Will this produce spoil?"

DeciFresh asks:

> "What is the best possible future for this batch right now?"
